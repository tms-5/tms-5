I like the part of front-end where product, design and engineering have to agree with each other.

My work usually lives around reusable components, scalable UI architecture, accessible experiences, and interfaces that are easy to use and easier to maintain. I have worked with React, Vue, Svelte, Lit, SAPUI5, WordPress, design systems, testing, documentation and cross-functional teams.

I care about the small things: the button label, the empty state, the loading behavior, the keyboard path, the component contract, the tiny visual detail that makes an interface feel intentional.
